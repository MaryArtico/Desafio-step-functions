# 🌀 Desafio AWS Step Functions — DIO

## 📘 Iniciando o Desafio

Este projeto faz parte do Bootcamp da DIO e tem como objetivo consolidar o conhecimento adiquirido em aula utilizando **AWS Step Functions**.

---

## 🎯 Objetivo

Construir um **workflow automatizado** com AWS Step Functions, aplicando os conceitos aprendidos e documentando a experiência.  
O resultado é um repositório organizado com anotações, códigos e imagens que demonstrem o entendimento do processo.

---

## 🧠 Conceitos Aplicados

- AWS Step Functions  
- AWS Lambda  
- Integração entre serviços da AWS  
- Criação fluxo de trabalho  
- Boas práticas de documentação técnica com GitHub

## Experiência com Step Functions

- Criei uma Step Function básica que chama uma Lambda que retorna "Olá Mundo".
- Fiz conforme aprendi na aula.
- Achei a experiência relativamente fácil, pois eu sou iniciante e foi meu primeiro contato com o Step Function. 
Minha execução apresentou erro e não consegui salvar, mas eu consegui capturar uma imagem do processo, e estou disponibilizando aqui como forma de mostrar que naveguei e testei a ferramenta.

## Notas
